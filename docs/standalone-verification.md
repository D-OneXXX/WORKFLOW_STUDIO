## 实际限制

- 本阶段尚未接入 MCP、Harness Agent 或模型 API。
- 执行进程具有用户权限，不是权限沙箱；不复制环境凭证，但不能阻止用户代码自行访问本机文件。
- 超时终止本次工作进程；用户代码主动派生的子进程不在该保证内。
- 运行状态和日志在完成后显示，不是流式。
- 没有自动迁移旧插件的数据或导入格式。
- 无 Git 仓库，因此没有提交或 PR。
