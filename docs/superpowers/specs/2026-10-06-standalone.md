# 独立工作流第一阶段

用户已采纳独立浏览器版、复用画布与编译器、自有存储及执行进程、先文件交互后接 Harness 的路线。

本阶段交付 localhost 浏览器应用；React 自行打包，不依赖 Harness 的模块加载器。Node 服务在独立数据目录中以 JSON 保存工作流，支持版本化 JSON 文件导入导出。服务通过子进程执行编译结果，超时强制终止子进程。代码节点是用户本地代码，进程隔离不是权限沙箱。

输入、代码、条件分支、输出可真实执行。大模型节点保留但报告连接器未配置；不伪造模型答案，不改动 Harness profile，不安装旧插件。MCP、Harness Agent 调用、流式状态和模型连接器属于后续阶段。

验收：离线加载页面不出现 dynamic require；保存后重启服务仍可读取；文件导出后可导入；无模型流程真实执行；无限循环超时后服务仍能响应；非法文件不覆盖存储。
